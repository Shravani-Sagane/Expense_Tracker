# Expense Tracker

A simple web application for tracking daily expenses and managing spending records.

## Features

* Add new expenses
* View all expenses in a table
* Categorize expenses
* Calculate total expenses automatically
* Delete expenses
* Simple and user-friendly interface

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Structure

```text
Expense-Tracker/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Clone the repository:

```bash
git clone 'https://github.com/Shravani-Sagane/Expense_Tracker.git'
```

2. Open the project folder.

3. Open `index.html` in your browser.
